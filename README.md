# Tallyon Demo

Standalone showcase and interactive coffee-store demo for Tallyon POS.

## Run locally

Open `showcase.html` in a browser, or serve this folder from a local web server. Choose **Open demo** to try the sample Brew & Bean store.

The demo is front-end only. Its coffee products, sales, inventory and settings are sample data; actions do not modify the main Tallyon application or a database.

## Files

- `showcase.html` — product showcase and entry point
- `demo.html` — interactive coffee-store sample
- `demo.css` — demo styles
- `demo.js` — demo interactions and sample products
